# NS MCP Server

Nederlandse Spoorwegen MCP Server built with Hono and Effect.

## Commands

- `bun run dev` - Start development server with hot reload
- `bun run start` - Start production server
- `bun run typecheck` - Type check with Effect Language Service diagnostics
